Tạo hợp đồng

API tự cấp mã CTxxxx, gắn phiên bản luật đang dùng, và sinh các mốc từ khuôn của loại hợp đồng (tiền = % × giá trị, hạn = ngày bắt đầu + số ngày). Loại hợp đồng phải có khuôn mốc cộng đủ 100%. Hợp đồng mới ở trạng thái DRAFT.
