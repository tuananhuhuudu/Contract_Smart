Contract Smart – trang thử

Ứng dụng (dữ liệu thật)

Đăng nhập bằng tài khoản demo, dựng thư viện mốc, loại hợp đồng, tạo hợp đồng, kích hoạt, ghi sự kiện. Ghi thật vào DB qua API.

Luồng thư viện mốc (xem trước)

Bấm thử toàn bộ luồng của thiết kế mới: thư viện mốc → loại hợp đồng → hợp đồng → sự kiện. Không ghi vào DB.

Tài liệu API (Swagger)

Các API đã dựng theo thiết kế mới. Hiện có: loại sự kiện, các bên.
